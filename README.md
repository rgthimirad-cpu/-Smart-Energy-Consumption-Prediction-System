# ⚡ Smart Energy Consumption Prediction System

## 📌 Overview

The **Smart Energy Consumption Prediction System** is a machine learning-based solution that analyzes historical electricity consumption data to forecast future energy demand, detect abnormal consumption, predict peak-demand periods, identify consumption patterns, and provide energy optimization recommendations.

## 🎯 Main Features

* 🔮 Time-Series Forecasting
* 🧠 LSTM / GRU Models
* 📈 Regression Models
* 🚨 Anomaly Detection
* ⚡ Peak-Demand Prediction
* 🧩 Consumption Clustering
* 💡 Optimization Recommendations
* 📊 Interactive Dashboard

## 📂 Dataset

The project uses the **Tetouan City Power Consumption Dataset**, containing historical electricity consumption data from 2017.

The historical dataset is used to learn consumption patterns and develop a predictive framework. It is not intended to represent current 2026 electricity consumption.
